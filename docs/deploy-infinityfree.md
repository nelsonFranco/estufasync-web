# Deploy no InfinityFree

## Enviar

- arquivos PHP;
- `paginas/`;
- `script/`;
- `style/`;
- `img/`;
- `manifest.json`;
- `service-worker.js`;
- `offline.html`;
- `icone.ico`;
- `.htaccess`;
- `config.php`, criado diretamente no servidor.

## Não enviar

- `banco/`;
- `docs/`;
- `.gitignore`;
- `README.md`;
- `config.example.php`;
- backups;
- arquivos RAR;
- logs;
- fotos locais.

O banco deve ser importado pelo phpMyAdmin.
