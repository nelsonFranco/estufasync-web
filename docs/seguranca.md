# Segurança

- Nunca publique `config.php`.
- Use HTTPS em produção.
- Gere um `app_secret` diferente por ambiente.
- Não coloque chaves ThingSpeak no JavaScript.
- Preserve o `.htaccess` da pasta de perfis.
- Não envie backups para o servidor público.
- Faça revisão antes de mesclar na branch `main`.
- Rotacione qualquer segredo exposto.
